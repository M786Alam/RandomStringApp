# Random String Generator App

An Android app built using **Jetpack Compose** and **MVVM architecture** that queries random strings from an external **Content Provider**.

## 🚀 Features

- Specify length of random string to generate
- Fetch random strings using a custom content provider
- Display metadata:
  - String value
  - Length
  - Timestamp
- Supports:
  - Generating multiple strings
  - Deleting individual strings
  - Clearing all entries
  - Error handling via Snackbar

## 🛠️ Tech Stack

- [Jetpack Compose](https://developer.android.com/jetpack/compose)
- [Kotlin](https://kotlinlang.org/)
- [MVVM Architecture](https://developer.android.com/jetpack/guide)
- [Content Provider](https://developer.android.com/guide/topics/providers/content-providers)
